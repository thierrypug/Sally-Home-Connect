Teste Sally kostenlos

Die Sally-Beta für Windows ist verfügbar. Du hast 30 Tage voller Testzeitraum, ohne Konto und ohne Kreditkarte. Eine Demo ist dabei, um alles zu entdecken, auch ohne Hardware.

Windows-Beta herunterladen Tester werden

Windows 10 oder 11 (64 Bit), etwa 80 MB. Die Datei liegt auf GitHub, wo du auch die Installationsanleitung und die Neuerungen jeder Version findest.

Tester werden

Wähle dein E-Mail-Programm: Eine fertige Nachricht öffnet sich, mit ein paar Fragen zu deinem Zuhause und deiner Hardware. Ausfüllen, abschicken, fertig. Auf dieser Seite wird nichts gespeichert.

Mit Gmail schreiben (öffnet in einem neuen Tab) Mit Outlook.com schreiben (öffnet in einem neuen Tab) Mit meinem E-Mail-Programm

Oder schreib einfach an sallyhomeconnect@gmail.com

Sally in drei Schritten installieren

Sonst nichts zu installieren: Alles, was Sally braucht, steckt in der Datei.

  1. Starte die Installation

    Doppelklicke auf die heruntergeladene Datei. Zeigt Windows „Der Computer wurde durch Windows geschützt“, wähle „Weitere Informationen“ und dann „Trotzdem ausführen“: Die Beta ist noch nicht signiert.

  2. Öffne Sally

    Das Desktop-Symbol öffnet Sally in deinem Browser. Beim ersten Mal zeigt er eine Warnung: Das ist normal, Sally hat ein eigenes Zertifikat. Wähle „Weiter“.

  3. Füge deine Geräte hinzu

    Steck deinen Zigbee- oder EnOcean-Stick ein: Sally führt dich, auf Wunsch per Sprache. Ohne Hardware öffnest du „Sally Home Connect - Démonstration“ (die Demo) im Startmenü.

Windows zum Testen, Raspberry Pi für den Alltag

Die Windows-Beta dient zum Kennenlernen. Für den Alltag läuft die finale Version auf einem Raspberry Pi: ein kleines, leises Gerät, das Tag und Nacht läuft, ohne Bildschirm und Tastatur.

Danach eine Lizenz, kein Abo

Nach dem Test wird Sally mit einer Lizenz für deine Installation aktiviert: Du zahlst einmal, ohne Abo. Der Preis wird zum Start bekannt gegeben.

Deine Meinung bringt Sally voran

Was funktioniert, was hakt, was dir fehlt, welche Hardware du hast: Alles interessiert uns. Schreib uns oder eröffne eine Anfrage im Tab „Issues“ der GitHub-Seite.

Ottieni Sally

Prova Sally gratis

La beta di Sally per Windows è disponibile. Hai 30 giorni di prova completa, senza account e senza carta di credito. È inclusa una demo per scoprire tutto, anche senza hardware.

Scarica la beta per Windows Diventa tester

Windows 10 o 11 (64 bit), circa 80 MB. Il file è pubblicato su GitHub, dove trovi anche la guida all'installazione e le novità di ogni versione.

Installare Sally in tre passaggi

Nient'altro da installare: tutto ciò che serve a Sally è nel file.

  1. Avvia l'installazione

    Fai doppio clic sul file scaricato. Se Windows mostra «PC protetto da Windows», scegli «Ulteriori informazioni» e poi «Esegui comunque»: la beta non è ancora firmata.

  2. Apri Sally

    L'icona sul desktop apre Sally nel browser. La prima volta compare un avviso: è normale, Sally ha un proprio certificato. Scegli «Continua».

  3. Aggiungi i tuoi dispositivi

    Collega la tua chiavetta Zigbee o EnOcean: Sally ti guida, anche a voce se vuoi. Senza hardware, apri «Sally Home Connect - Démonstration» (la demo) dal menu Start.

Windows per provarla, Raspberry Pi per viverci

La beta per Windows serve a scoprire Sally. Per adottarla, la versione finale girerà su un Raspberry Pi: una piccola scatola silenziosa che resta accesa giorno e notte, senza schermo né tastiera.

Poi una licenza, non un abbonamento

Dopo la prova, Sally si attiva con una licenza fatta per la tua installazione: paghi una volta, senza abbonamento. Il prezzo sarà annunciato al lancio.

La licence de ta Sally

Tu paies une fois, sans abonnement. La licence est faite pour l'appareil d'où tu viens : ton ordinateur ou ton Raspberry Pi.

Ton code d'installation

—

Ouvre cette page depuis Sally : Réglages, puis « Acheter Sally ». Le code de ton appareil s'affichera ici.

Le paiement se fait sur une page sécurisée. Ensuite, touche « Retour à Sally » : elle s'active toute seule, et ta licence t'est aussi envoyée par e-mail.

Pendant la bêta, écris-nous avec ton code d'installation : nous t'enverrons ta licence. Le message est déjà prêt, avec ton code.

Une licence par appareil

Ton ordinateur d'essai et ton Raspberry Pi ont chacun leur code. Achète la licence depuis l'appareil avec lequel tu vis : en général, le Raspberry Pi.

Ta maison est gardée

À la fin de l'essai, rien n'est effacé. Dès que Sally est activée, tu retrouves ta maison, tes routines et tes réglages.

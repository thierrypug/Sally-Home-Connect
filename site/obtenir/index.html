Obtenir Sally

Essaie Sally gratuitement

La bêta de Sally pour Windows est disponible. Tu as 30 jours d'essai complet, sans compte et sans carte bancaire. Une démonstration est incluse pour tout découvrir, même sans matériel.

Windows 10 ou 11 (64 bits), environ 80 Mo. Le fichier est publié sur GitHub, où se trouvent aussi le guide d'installation et les nouveautés de chaque version.

Installer Sally en trois étapes

Rien d'autre à installer : tout ce dont Sally a besoin est dans le fichier.

  1. Lance l'installation

    Double-clique sur le fichier téléchargé. Si Windows affiche « Windows a protégé votre ordinateur », choisis « Informations complémentaires » puis « Exécuter quand même » : la bêta n'est pas encore signée.

  2. Ouvre Sally

    L'icône du Bureau ouvre Sally dans ton navigateur. La première fois, il affiche un avertissement : c'est normal, Sally a son propre certificat. Choisis « Continuer ».

  3. Ajoute tes appareils

    Branche ta clé Zigbee ou EnOcean : Sally te guide, à la voix si tu veux. Sans matériel, ouvre « Sally Home Connect - Démonstration » dans le menu Démarrer.

Windows pour essayer, Raspberry Pi pour vivre avec

La bêta Windows sert à découvrir Sally. Pour l'adopter, la version finale tournera sur un Raspberry Pi : un petit boîtier silencieux qui reste allumé jour et nuit, sans écran ni clavier.

Ensuite, une licence, pas un abonnement

Après l'essai, Sally s'active avec une licence faite pour ton installation : tu paies une fois, sans abonnement. Son prix sera annoncé à la sortie.
